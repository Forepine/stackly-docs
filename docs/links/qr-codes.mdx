---
title: QR codes
description: Show, save and share the QR code that comes with every short link, and print it so it scans every time.
---

Every short link gets its own QR code automatically. Put it on a menu card, a shop counter or a flyer, and people can scan it with their phone camera.

<Shot id="links/qr-panel" title="A link card flipped to its QR code with Save and Share buttons" />

## Show a link's QR code
1. In the left menu, click **Links**.
2. On the link, click the QR icon.
   - In grid layout, the card flips over to show the code.
   - In list layout, the code opens under the link.
   <Shot id="links/qr-list-view" title="QR code open under a link in list layout" />
3. To hide it again, click the back arrow, or click the QR icon again.

The QR icon only works while the link is active.

## Save the QR code
1. Open the QR code as above.
2. Click **Save**.

You get a PNG image named after the back-half, for example `diwali-sweets-QR.png`.

## Share the QR code
1. Open the QR code.
2. Click **Share**.

On a phone, this opens your share menu so you can send the image on WhatsApp or email. If your browser can't share, Stackly copies the short link instead.

## Print tips
- Print it at least 2 × 2 cm. For posters and banners, go bigger: about 1 cm of code for every 10 cm of scanning distance.
- Keep it dark on a light background. Don't print it in light colours or over a photo.
- Leave a clear white border around the code.
- Add a short line next to it, like "Scan for today's menu".
- Scan the printed proof with two different phones before you print hundreds.

## Good to know
- You can't change the colours or add a logo to the QR code yet.
- The code opens the short link, so it follows the link's rules: if you pause the link or it expires, the code stops working too.
- If you change the back-half, the old QR code stops working. Save and print the new one.

## Troubleshooting
- **"QR Code not available"** → Edit the link and click **Save changes**. Stackly makes a fresh code.
- **The code scans but shows a "not found" or "turned off" page** → Check the link is active and the back-half hasn't changed. See [what visitors see](./what-visitors-see).
